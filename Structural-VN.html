4 Spanwise Load Distribution

How much bending moment and shear are actually left at each span station, root to tip — using the same elliptical lift distribution as the root check below, just evaluated at more than one point. This is where a real spar would taper: loads drop off fast toward the tip, so a constant root-sized cross-section the whole way out is carrying far more material than it needs outboard. Split into Main/Rear the same way as the root numbers, by the Bending Share set on Step 3. Not affected by the Trial Dimensions below — this is load only, independent of what cross-section you choose. Hover either curve for the exact value at a station.

4 Trial Dimensions

Propose dimensions for each spar — Step 6 tells you if they're enough, same "propose, then check" pattern as the rest of this tool. Each diagram shows the selected cross-section shape and what each field name refers to, sized from that spar's own current values. Each spar's own "Solve for Minimum Size" scales that spar's currently-entered shape down (or up) to hit its own target margin — it keeps the proportions you've set, it doesn't invent a new shape, so it can't wander into a thinner-than-checked flange or web this tool wouldn't catch (this tool doesn't model buckling).

5 Section Transition

Optional — additional stations further out along the span, beyond the root. Loads drop off fast toward the tip (see Spanwise Load Distribution on Step 4), so a real spar usually tapers rather than carrying the root's cross-section the whole way out. These are separate from Step 4 Trial Dimensions / Step 6 Results — the root check isn't affected by anything here.

Summary

Torsion Check

Checked at the root (stressed-skin) / uniformly across every bay (fabric/truss), not swept along span — and this is provably sufficient, not a shortcut. Under this tool's constant-chord assumption, Am/skin thickness/bracing don't vary along span, so stress and bracing load scale directly with torque — which is highest at the root and decreases toward the tip (stressed-skin), or identical bay-to-bay (fabric/truss, since the distributed torque per unit span doesn't vary along span here). No outboard station or bay can show a worse result than what's already checked.
